EUNSUNG EMBROIDERY · 배포 가이드

은성자수 홈페이지
인터넷에 올리는 방법

도메인 사기 → 깃허브에 올리기 → 도메인 연결 → 나중에 고치기. 컴퓨터를 잘 몰라도 순서대로 따라 하면 됩니다. 총 1~2시간, 비용은 도메인값(1년에 약 1~2만 원)뿐입니다.

1단계가비아에서 도메인 사기홈페이지 "주소"를 삽니다
2단계깃허브에 파일 올리기홈페이지 "집"을 무료로 빌립니다
3단계배포 켜기인터넷에 공개합니다
4단계주소와 집 연결내 도메인으로 열리게 합니다
차례
  1. 시작하기 전 준비물
  2. 가비아에서 도메인 사기
  3. 깃허브 계정 · 저장소 만들고 파일 올리기
  4. 배포 켜기 (GitHub Pages)
  5. 도메인 연결하기
  6. 나중에 내용 고치는 방법
  7. 막힐 때 보는 곳

시작하기 전 준비물

미리 알아둘 단어 3개 도메인 = 홈페이지 주소 (예: eunsungjasu.com).   저장소(Repository) = 깃허브 안에 만드는 폴더 하나. 여기에 홈페이지 파일을 넣습니다.   배포 = 넣어둔 파일을 인터넷에 공개하는 것.

1단계 · 가비아에서 도메인 사기

이미 갖고 계신 컴퓨터자수.net 을 그대로 쓰셔도 됩니다. 그 경우 이 단계는 건너뛰고, 4단계에서 "가비아" 대신 그 도메인을 산 업체의 관리 화면에서 똑같이 설정하면 됩니다. 새 영문 도메인(예: eunsungjasu.com)을 하나 더 사서 쓰는 것을 권합니다. 한글 도메인은 연결 과정에서 문제가 생길 수 있습니다.

1

가비아 접속 후 로그인

www.gabia.com → 오른쪽 위 로그인 (없으면 회원가입, 무료).

2

원하는 주소 검색

첫 화면 가운데 검색창에 원하는 이름을 영문으로 입력. 예: eunsungjasu

결과 목록에 .com / .co.kr / .kr 등이 나옵니다. "등록 가능"이라고 표시된 것만 살 수 있습니다. .com 또는 .co.kr 을 고르세요.

3

장바구니 → 결제

원하는 주소 옆 신청하기 → 등록 기간 선택(1년 또는 2년) → 결제하기.

같이 권하는 부가서비스는 전부 체크 해제웹호스팅, 홈페이지 제작, 보안 서비스 등은 필요 없습니다. 도메인 값만 내면 됩니다 (.com 기준 1년 약 15,000~20,000원).
4

관리 화면 위치 확인해 두기 (4단계에서 씁니다)

오른쪽 위 My가비아 → 서비스 관리 → 도메인 탭 → 방금 산 도메인 옆 관리 버튼 → DNS 정보 줄의 DNS 설정.

여기서 "레코드 추가"라는 버튼이 보이면 제대로 찾은 것입니다. 지금은 아무것도 만지지 말고 창을 닫아도 됩니다.

2단계 · 깃허브에 파일 올리기

사촌동생 계정으로 진행합니다. 컴퓨터에 GitHub Desktop 을 먼저 설치해 두세요.

2-A. 저장소(폴더) 만들기 — 인터넷 화면에서

1

github.com 로그인

github.com → Sign in.

2

새 저장소 만들기

오른쪽 위 + 버튼 → New repository.

3

이름 정하고 만들기

Repository name 칸에 영문으로 eunsung-site 입력 (띄어쓰기 없이).

Public 을 선택 (Private 이면 무료 공개가 안 됩니다).

나머지 체크박스("Add a README" 등)는 전부 건드리지 않고 맨 아래 초록색 Create repository 클릭.

파란색 안내문이 잔뜩 있는 화면이 나오면 성공입니다. 이 화면은 닫아도 됩니다.

2-B. 파일 올리기 — GitHub Desktop 프로그램에서

4

GitHub Desktop 열고 로그인

처음 실행하면 Sign in to GitHub.com 버튼이 있습니다. 클릭하면 브라우저가 열리고 로그인 → "Authorize" 를 누르면 프로그램으로 돌아옵니다.

5

방금 만든 저장소를 내 컴퓨터로 가져오기

메뉴 File → Clone repository → 목록에서 eunsung-site 선택 → Local path(저장 위치)는 그대로 두고 → Clone.

내 컴퓨터 문서\GitHub\eunsung-site 폴더가 생깁니다. (Local path 에 적힌 경로가 그 위치입니다.)

6

홈페이지 파일을 그 폴더에 복사

전달받은 은성자수-새사이트 압축을 풀고, 그 안의 index.html 과 img 폴더를 위 eunsung-site 폴더 안에 복사해 넣습니다.

폴더 안에 또 폴더가 들어가면 안 됩니다eunsung-site 폴더를 열었을 때 바로 index.html 이 보여야 합니다. eunsung-site\은성자수-새사이트\index.html 처럼 되면 홈페이지가 안 뜹니다.
7

올리기 (Commit → Push)

GitHub Desktop 으로 돌아오면 왼쪽에 파일 목록이 쭉 나타납니다 (270개쯤).

왼쪽 아래 Summary 칸에 아무 말이나 입력 (예: 홈페이지 올림) → 파란색 Commit to main 클릭.

그다음 위쪽에 나타나는 Push origin 버튼 클릭. 1~2분 기다리면 끝.

github.com 의 eunsung-site 페이지를 새로고침하면 index.html 과 img 폴더가 보입니다.

3단계 · 배포 켜기 (GitHub Pages)

1

저장소 설정으로

github.com 에서 eunsung-site 저장소 페이지 → 위쪽 탭 맨 오른쪽 Settings (톱니바퀴).

2

Pages 메뉴

왼쪽 메뉴에서 Pages 클릭.

3

어디서 공개할지 고르기

Build and deployment 아래 Source 는 Deploy from a branch 그대로.

Branch 에서 None → main 으로 바꾸고, 옆 칸은 / (root) → Save.

4

1~3분 기다린 뒤 새로고침

같은 화면 맨 위에 Your site is live at https://아이디.github.io/eunsung-site/ 라고 뜹니다. Visit site 를 누르면 홈페이지가 열립니다.

이 주소는 이미 누구에게나 공유 가능합니다. 도메인 연결(4단계)은 이 주소를 예쁜 주소로 바꾸는 작업입니다.

4단계 · 도메인 연결하기

깃허브와 가비아 양쪽에 각각 한 번씩 설정합니다. 예시 도메인은 eunsungjasu.com, 깃허브 아이디는 아이디 라고 쓰겠습니다. 실제 값으로 바꿔 넣으세요.

4-A. 깃허브 쪽

1

Settings → Pages → Custom domain

3단계와 같은 화면 아래쪽 Custom domain 칸에 eunsungjasu.com 입력 → Save.

"DNS check in progress" 또는 빨간 경고가 떠도 정상입니다. 가비아 설정을 아직 안 했기 때문입니다.

4-B. 가비아 쪽

2

DNS 설정 화면 열기

1단계 4번에서 봐둔 곳: My가비아 → 서비스 관리 → 도메인 → 관리 → DNS 설정. 화면 안 설정 또는 레코드 수정 버튼을 누르면 편집 모드가 됩니다.

3

레코드 5줄 추가

레코드 추가 를 눌러 아래 표대로 한 줄씩 넣습니다. 이미 있는 줄은 지우지 않아도 되지만, "@" 로 시작하는 A 레코드가 다른 값으로 이미 있으면 그 줄은 지웁니다.

타입호스트값 / 위치TTL
A@185.199.108.153기본값(3600)
A@185.199.109.153기본값
A@185.199.110.153기본값
A@185.199.111.153기본값
CNAMEwww아이디.github.io. (사촌동생 깃허브 아이디, 맨 끝에 점)기본값

다 넣었으면 저장. "적용되었습니다" 안내가 나옵니다.

CNAME 값 끝의 점(.)가비아는 끝에 점을 붙여야 저장되는 경우가 있습니다. 점을 붙였는데 오류가 나면 점을 빼고 다시 저장해 보세요.
4

기다리기 (10분 ~ 길면 하루)

브라우저 주소창에 eunsungjasu.com 을 쳐서 홈페이지가 뜨면 성공. 안 뜨면 시간을 두고 다시 확인하세요. 보통 30분 안에 됩니다.

5

자물쇠(https) 켜기

연결이 된 뒤 깃허브 Settings → Pages 로 돌아가면 Custom domain 아래 초록색 DNS check successful 이 보입니다. 그 밑 Enforce HTTPS 체크박스를 켜세요. 회색으로 눌리지 않으면 1시간쯤 뒤 다시 시도.

5단계 · 나중에 내용 고치는 방법

홈페이지 내용은 전부 index.html 파일 한 개 안에 글자로 들어 있습니다. 파일을 고치고 → GitHub Desktop 에서 올리면 → 1~2분 뒤 인터넷에 반영됩니다.

글자 바꾸기 (전화번호, 주소, 문구)

1

파일 열기

문서\GitHub\eunsung-site\index.html 을 마우스 오른쪽 클릭 → 연결 프로그램 → 메모장. (더 보기 편한 무료 프로그램: VS Code)

2

찾아서 바꾸기

Ctrl+H → "찾을 내용"에 예전 글자, "바꿀 내용"에 새 글자 → 모두 바꾸기.

전화번호처럼 여러 곳(상단 버튼, 고객센터, 하단)에 같은 글자가 있으면 "모두 바꾸기"가 한 번에 처리합니다.

3

저장 후 올리기

Ctrl+S 저장 → GitHub Desktop 열기 → 왼쪽에 index.html 이 보이면 Summary 에 전화번호 수정 같은 메모 → Commit to main → Push origin.

꺾쇠 괄호 < > 안의 영문은 건드리지 마세요화면에 보이는 한글 문구만 바꾸면 안전합니다. <div class="..."> 같은 부분을 지우면 화면이 깨집니다. 깨졌으면 GitHub Desktop 에서 파일을 오른쪽 클릭 → Discard changes 로 되돌릴 수 있습니다.

제품 사진 추가하기

1

사진 파일 넣기

사진을 영문 이름(예: new01.jpg)으로 바꿔 eunsung-site\img\products 폴더에 넣습니다. 한글 이름은 피하세요. 흰 배경 사진이 제일 예쁘게 나옵니다.

2

목록에 한 줄 추가

index.html 에서 Ctrl+F 로 const ITEMS 를 찾습니다. 바로 뒤 [ 다음에 아래 한 줄을 붙여 넣습니다 (끝의 쉼표까지).

{"c":"char","t":"곰돌이 와펜 8x9 사이즈","f":"new01.jpg"},

"c" 는 분야 코드, "t" 는 화면에 보일 제목, "f" 는 사진 파일 이름입니다.

분야코드분야코드분야코드
악세사리자수acc유치원마크kinder각종마크mark
보풀자수chenille캐릭터자수char가방자수bag
메탈핸드메이드metal네임택nametag각종명찰badge
3

저장 후 올리기

위와 똑같이 저장 → GitHub Desktop → Commit → Push.

제일 쉬운 방법파일을 직접 고치기 부담스러우면, 바꿀 내용(예: "전화번호를 010-0000-0000 으로", "이 사진 5장을 캐릭터자수에 추가")을 Claude 에게 말하고 고쳐진 index.html 을 받아서 GitHub Desktop 으로 올리기만 해도 됩니다.

막힐 때 보는 곳

주소를 열면 "404 There isn't a GitHub Pages site here" 라고 나옵니다.
3단계 Branch 가 main / / (root) 로 저장됐는지, 그리고 저장소 첫 화면에 index.html 이 바로 보이는지 확인하세요. 폴더 안에 폴더로 들어가 있으면 404가 납니다. 저장 직후라면 3분만 기다려 보세요.
홈페이지는 뜨는데 사진이 하나도 안 보입니다.
img 폴더가 같이 올라갔는지 github.com 에서 확인하세요. 폴더 이름은 소문자 img 여야 합니다.
도메인을 쳐도 "사이트에 연결할 수 없음"이 나옵니다.
가비아 DNS 반영 대기 중일 수 있습니다(최대 하루). 하루가 지나도 안 되면 A 레코드 4줄의 숫자 오타, 호스트가 @ 인지, CNAME 값의 아이디 철자를 확인하세요.
깃허브에 "Enforce HTTPS" 가 회색이라 못 누릅니다.
DNS 연결 확인이 끝나야 활성화됩니다. 초록색 "DNS check successful" 이 뜬 뒤 1시간쯤 후 다시 시도하세요.
GitHub Desktop 에 "Push origin" 버튼이 안 보입니다.
먼저 Summary 에 글자를 넣고 Commit to main 을 눌러야 그 뒤에 나타납니다.
도메인은 매년 돈을 내야 하나요?
네, 도메인만 1년마다 갱신(약 1~2만 원). 가비아에서 자동 연장을 켜두면 잊지 않습니다. 깃허브 호스팅은 계속 무료입니다.
사촌동생 계정으로 만들었는데 나중에 제 계정으로 옮길 수 있나요?
가능합니다. 저장소 Settings 맨 아래 Transfer ownership 으로 다른 아이디에게 넘길 수 있습니다. 넘긴 뒤 3단계와 4-A 를 새 계정에서 한 번 더 하면 됩니다.
